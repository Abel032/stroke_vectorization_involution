# 论文复现与工程扩展声明

本文采用的骨架和边界拓扑步骤主要参考 Zhang et al., 2022, *Vectorizing Line Drawings of Arbitrary Thickness via Boundary-based Topology Reconstruction*, DOI 10.1111/cgf.14485 的第 4.1–4.3 节。具体包括 Zhang–Suen 细化、骨架/边界拓扑、基于切向一致性的伪分支移除、交汇处重建和二次曲线外推。

其余细节（端点/交点聚簇、非唯一的交汇段续接、候选边界的像素匹配策略）属于该项目的工程近似，并非论文公开的作者官方实现。对于线稿中的分支重叠、遮挡层次、真正绘画顺序，无法根据二值图可靠还原。

**单段平均线宽**是本项目根据用户需求新增的简化估计，并**非原论文的线宽恢复方法**。内部只取 `2*EDT-0.5` 的代表性均值；不会试图逐点还原左右边界或笔压函数。对复杂交点以及偏心骨架，均值只供 GNN 下游几何特征使用，不应当作为精确矢量重建真值。

为了保持用户现有 GNN 的训练与图缓存稳定，GNN 后端默认 `legacy`；`boundary` 是显式开关，并对 4 连通 Region 的变化采取回退策略。不会修改 GNN Line 5D 或 L-L Edge 2D 的现有定义。
