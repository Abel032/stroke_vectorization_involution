# 算法原理与复现说明

**论文**：Zibo Zhang, Xueting Liu, Chengze Li, Huisi Wu, Zhenkun Wen. *Vectorizing Line Drawings of Arbitrary Thickness via Boundary-based Topology Reconstruction.* Computer Graphics Forum, 41(2), 2022. DOI: 10.1111/cgf.14485.

**状态**：基于论文描述独立开发的可运行 Python 原型。为区分论文原意和本项目的具体选择，正文分别标为「论文」和「本实现」。

## 1. 为什么用边界修复骨架？

普通二值细化算法先将宽线条压成单像素骨架，但在 T、X、Y 交汇、锐角和变线宽的位置，骨架会发生偏移、过早合并、生成多余尖刺，甚至误将相邻的粗线连接。

论文的核心观察：**真实连续线条的左右边界通常具有连续的切线与走向，因此边界可以帮助判断骨架是不是可靠，以及错误骨架应该如何补回。** 论文第 3 节图 3 展示完整流水线，图 6–7 展示假尖刺/假连接删除，图 8–11 展示骨架重建。

输入：带粗细变化的线条图像 `I ∈ [0,255]^(H×W)`。输出：由 `(N,2)` 浮点像素坐标构成的多条中心曲线，及 SVG。

主步骤：二值化与细化 → 建立骨架、边界拓扑 → 移除不可靠骨架段 → 边界/拓扑引导修复 → 输出矢量曲线。

## 2. 第 3 节：预处理

**论文**：二值化后，利用 Zhang–Suen 等经典细化算法提取初始骨架；所有与至少一个背景像素 8 邻接的线条像素视作边界像素。

**本实现**：`preprocess()` 使用灰度+Otsu（也可固定阈值）以及连通分量小噪声去除；`skeletonize()` 优先调用 OpenCV contrib 的 Zhang–Suen `cv2.ximgproc.thinning`，若无 contrib 则调用本项目的 NumPy 向量化 Zhang–Suen 两阶段迭代实现 `_zhang_suen`；`Boundaries` 使用 `cv2.findContours(..., RETR_LIST, CHAIN_APPROX_NONE)` 得到有序轮廓，`result.boundaries` 把这些像素显示为边界图。

坐标约定：所有向量点 `(x,y)`，左上角为 `(0,0)`，图像访问时 `image[y,x]`。

## 3. 论文 4.1：骨架与边界的拓扑构建

### 3.1 骨架拓扑 4.1.1

给单像素骨架建立图：骨架像素为顶点，相邻像素连边，度数=1 为端点，度数≥3 为交汇点，其他度数=2 为中间点。沿中间点追踪路径，得到端点与交汇点之间的线段。没有端点的纯环形结构保留为一条闭合曲线。

为消除离散 8 邻域造成的假三角边，本实现删除会构成短路的斜对角连接；相邻的多个交汇像素聚成一个交汇节点，其位置取像素坐标均值。各骨架段用 `scipy.interpolate.splprep` 拟合平滑样条，并重新以约 0.5 像素间隔采样。论文给出平滑参数 `0.05`；SciPy 的 `s` 与论文引用的优化样条目标函数**不一定严格同义**，本项目使用 `s = 0.05×点数` 作为工程映射。

核心函数：`skeleton_graph()`、`smooth_curve()`、`resample()`。

### 3.2 边界拓扑 4.1.2

论文提出：沿边界跟踪像素，拟合光滑矢量曲线；若拟合曲线与栅格原线的最大偏离超过 1 像素，则在该位置拆段、重新拟合。这样将尖角附近不同语义的边界拆开，不使其被一条样条抹平。

本实现用 OpenCV 有序轮廓 + 4 像素左右对称弦求边界切线，按宽度为 3–6 像素的前后切向夹角筛选高曲率点并给弧段分组。**这是论文 1px 残差递归拟合的近似**，能对明显尖角分段，但不保证复杂细节下与作者的边界分段一致。

核心类：`Boundaries`（`contours`、`tvec`、`groups`）。

## 4. 论文 4.2：不可靠骨架删除

### 4.1 骨架出发的切线一致性：式 (1)(2)

对某骨架段 `c` 每隔不超过 0.5 像素取样中心点 `c_i`，通过中心曲线切线 `t_i` 的两个法线方向射线投射到边界 `b_l(c_i)` 与 `b_r(c_i)`。论文比较骨架切线和两条边界的归一化内积：

\[
D_{skeleton}(c_i)=\max\left(\frac{t(c_i)\cdot t(b_l)}{\|t(c_i)\|\,\|t(b_l)\|},\frac{t(c_i)\cdot t(b_r)}{\|t(c_i)\|\,\|t(b_r)\|}\right).
\]

论文对端点-交汇点类型的**尖刺候选段**使用判据：若该段全部点 `D_skeleton < 0.99`，则删去该段。

本实现：`Boundaries.normal_hit()` 以 0.5 像素射线扫描，利用首次离开前景的点搜索轮廓 KDTree；`Boundaries.initiated()` 计算左右两侧与中心切线的匹配程度。考虑反向遍历的轮廓与中心曲线可能指向相反方向，本实现采用余弦的**绝对值**（把无向切线视为等价）；因此和正文公式的有向余弦符号处理存在差异。

### 4.2 边界引导的完整性：式 (3)

论文发现某些虚假尖刺的局部切线可能看起来一致，但左右边界实际上与邻近的多条中心骨架段相关联，因此可依据骨架-边界多对一映射判断，补足切线一致性检测。

本实现：统计候选段左右侧所关联的边界分组 ID，与同一交汇点处其他段的分组重合程度；只有两侧都共享、边界分组确实拆成至少两个，并且候选段相对于局部线宽很短、其切线在一定范围内不可靠时才删除。该额外约束是**为避免误删真实 T/Y 长分支的保守启发式**，并不等于严格复现论文完整的 `Ind(c(b_i))` 映射。

核心函数：`classify_segments()`，可以通过 `--no-completeness` 关闭。

### 4.3 假连接删除：式 (4)

具有两个交汇点的线段可能是误连接。论文除骨架出发的法线匹配外，还从边界点 `b_i` 的法线向骨架点 `c_i` 投射，定义边界出发的一致性：

\[
D_{boundary}(c_i)=\max_{b_i\to c_i}\frac{t(c_i)\cdot t(b_i)}{\|t(c_i)\|\,\|t(b_i)\|}.
\]

论文对整段**所有点**同时不满足 `D_boundary >= 0.95` 与 `D_skeleton >= 0.99` 的情况，判为假连接并删除。

本实现：`Boundaries.boundary_initiated()` 使用 KDTree 查询中心点附近不超过 48 个候选边界像素，只保留边界法线近似指向该中心点的边界点（切线与连接方向的点积绝对值不超过 0.34），取最大无向切线一致性。由离散搜索带来的偏差可能对短小连接敏感。

## 5. 论文 4.3：失真中心线的重建

### 5.1 标记不可靠像素与切断

论文：如果中心点的法线投射找不到可靠边界，或中心线/边界的切线不一致，则将该中心点判为不可靠。剪掉这些点后，交汇附近可能出现断线。对各断线端提取靠近交汇处的可靠截断点。

本实现：为避免局部栅格误差引发整段崩溃，仅从各交汇端向内部寻找连续两个可靠样本并裁去不可靠前缀（最大裁切 22px，且依赖局部距离变换宽度）。原始骨架段的远端和环形结构优先保留。该策略是稳定性启发式。

### 5.2 边界引导重建：4.3.1（图 8）

论文：如两个断线端共享一条连续的边界，则取对应的边界弧段，**沿中心线移动、缩放**后复制到缺失中心线位置，使两段连接。

本实现：`Boundaries.reference_patch(ea, eb)` 检查两个断线端映射到的左右边界是否具有共同边界分组和同轮廓位置，选择较短连续边界弧段，计算端点处从边界到中心线的位移 `δ_a,δ_b`，对边界弧长插值：

`patched(u) = boundary(u) + (1-u)*δ_a + u*δ_b`, `u ∈ [0,1]`。

这样端点精确落在两个断线截点，曲线形状受边界控制；和论文的复制/平移/缩放思想一致，但没有作者原始的曲线重新参数化规则。

### 5.3 拓扑引导重建：4.3.2（图 9–10）

论文：先把截断点处余弦距离 ≤0.01（即余弦 ≥0.99）的共线骨架端点直接连接，并合并线段。余下的不匹配断线，用**二次多项式**拟合断线并向前延伸到边界，在交汇位置裁切多余延伸，修复拓扑。

本实现：同一交汇点内，优先连接共享边界参考片段且方向相对的两个端点；否则将夹角接近反向共线（`-dot >= 0.99`）的端点以直线连接；剩余分支用截止点附近样本的 `x(s), y(s)` 二次多项式外推，再以三次平滑修正将终点落在原交汇位置或刚修复的交叉中心线上。

与论文不同，本项目**不会将所有曲线延伸到真实轮廓再选择最远交汇点**，而是利用原始聚类交汇点作几何定位，因此高密度交叉或低信噪比情况下可能出现额外短线。所有补线以独立 SVG Path 保存，端点几何上吻合，但不做额外复杂图链合并。

## 6. 矢量导出

`_svg_path()` 将各中心线按约 0.65 像素容差简化，利用 Catmull–Rom 转立方 Bézier 控制点的公式输出 SVG `M/C` 路径。`--svg-mode centerline` 输出 1px（可调）黑色中心线。

如选 `--svg-mode original`，`save_svg()` 沿各中心线每隔 3 像素采样，按 `distance_transform_edt` 对中心线到边界的距离设置分段宽度，画圆端线条。原图含连接、交叠时半径可能高估，这是演示功能而不是论文中心线评价目标。

## 7. 测试与量化

`demo.py` 生成 512×512 的 T/X/Y 交汇、闭合圆环、变线宽曲线，并在 `examples/*_gt.png` 放置**由绘制函数独立生成的理想单像素中心线**。`tests/test_vectorizer.py` 覆盖典型拓扑、SVG 输出、空输入、反相输入以及几何基本误差，执行：

```bash
python demo.py
python -m pytest -q
```

### 7.1 Chamfer 距离：论文式 (5)

预测中心线像素集合 `A` 与真值集合 `B` 的双向距离变换平均：

\[
C(A,B) = \frac{1}{2|A|}\sum_{a\in A} DT_B(a) + \frac{1}{2|B|}\sum_{b\in B} DT_A(b).
\]

本实现使用欧氏距离变换并按图像对角线归一化；这是一种明确、可复现的归一化，论文正文并未完整展开归一化距离变换的实现细节，因此**数字不能直接和论文表 1 对比**。

### 7.2 Occupancy（容差命中率）

实现使用 `|A ∩ dilate_3(B)| / |A| ×100%`，即预测中心线中落入真值 3×3 膨胀范围的比例。这符合论文将 occupancy 描述为“放宽的预测精度”的文字，但论文式 (6) 的排版分母可被解读为膨胀真值范围，因此这里**显式声明了所采用的具体定义**。

当前测试只证明代码能运行且简单构造能取得合理的拓扑与误差，不等于复现作者的真实图像测试，也不能保证复杂插画可靠。

## 8. 最重要的差异与复现风险清单

| 论文信息 | 本项目选择 | 影响 |
|---|---|---|
| Zhang–Suen thinning | OpenCV contrib 优先，缺失时纯 NumPy Zhang–Suen | 都遵循 Zhang–Suen 规则，但边界条件和细节仍可能存在差异 |
| 优化样条平滑参数 0.05 | SciPy `splprep(s=0.05×N)` | 曲线可能轻微不同 |
| 边界曲线最大偏差 >1px 递归切段 | 前后切向夹角检测尖角 | 弱尖角或复杂边界语义分段可能不同 |
| 骨架/边界投射和切线算子 | 0.5px 离散射线、KDTree 邻近、无向余弦 | 对误差阈值较敏感 |
| 骨架-边界多对一映射式 (3) | 按交汇邻段集合共享 + 短段条件 | 保守但可能漏删假尖刺 |
| 无法靠边界引导时延伸到轮廓并裁切 | 二次拟合 + 对原交汇节点几何修正 | 复杂 X/Y 位置精度受限 |
| 论文图 11 中线条精简/美化 | Catmull–Rom Bézier 输出 | 形状和原作者不一定相同 |

## 10. 新增 Stroke 层的拓扑标记与归并

**为什么需要：** 旧版 `reconstruct()` 把裁剪保留的骨架片段和桥接线都追加到 `result.strokes`，但这些只是绘制图元，并没有给出“哪几段属于同一条完整笔画”的可查询标识。仅靠 SVG 中线段端点的几何重合，也无法区分 **X 交叉的两条贯通笔画** 与 **T 交汇的贯通 + 终止笔画**。

**目前实现：** `reconstruct()` 将跨段配对及补线方式以结构化 `bridge_records` 记录，`stroke_topology.assemble_strokes()` 把每段保留的骨架片段视为一条拓扑图边；遇到边界 / 切线判为连续的两个截断端点（`boundary` 或 `tangent`）就将它们**合并进同一条语义 Stroke**，其间的曲线连接作为几何桥接保留；`extrapolate` 仅延长对应 Stroke，不会把相交但没有配对的两条笔画强行合成一条。

这构成“原始骨架段（Segment）→ 段端口配对（Bridge）→ 完整 Stroke（S#）”三级映射。**图拓扑判别和可视化层的标签是为了实际使用而额外增加的输出，不是论文明确给出的标签格式。**

### 10.1 输出字段

- `result.strokes`：保留旧兼容接口，`list[np.ndarray]`，每条是一个**基础几何图元**，其中包括未拼接的骨架片段和单独的桥接曲线。
- `result.semantic_strokes`：新增 `list[np.ndarray]`，每条是按端口配对推断的**完整笔画**，按 S0、S1… 顺序排列。
- `result.topology`：机器可读字典，包含 `strokes`、`junctions`、`nodes`、`bridges`。其中 `strokes[].segment_ids` 允许追溯原始段，`strokes[].start_node` / `end_node` 标注拓扑端点，`strokes[].via_junctions` 记录经过的交汇点。
- `junctions[].continuations`：明确记录本交汇处哪些原始分支接成**同一条 Stroke**，包括匹配方法 `boundary` / `tangent` 与出射方向余弦 `outgoing_cosine`；`ending_strokes` 为在此交汇处终止的 Stroke。
- `junctions[].kind`：根据该节点的骨架度数以及是否存在几何上近似反向（余弦 < -0.9）的配对，标记 `X_crossing`、`T_junction`、`Y_or_three_way_junction` 等。该类型是局部几何推断，不是图层关系。
- `*_topology.json`：保存抽稀的 `polyline_xy` 以减少文件体积；`*_topology.svg` 保留可编辑的每条完整 Stroke SVG `<g id="stroke-S#">`；`*_topology.png` 适合快速查看编号（PNG 是 2× 分辨率）。

### 10.2 例子与不可判定信息

X 形：4 段骨架 → 2 条连续 Stroke、交汇 J0（`X_crossing`，两组 `continuations`）。

T 形：3 段骨架 → 2 条 Stroke，主干贯通 J0，支线在 J0 终止（`T_junction`）。

Y 形：3 段骨架且几何三向；即使边界提示某两支应连续，节点仍标记为 `Y_or_three_way_junction`，防止把明显非共线的 Y 误称 T。三分叉处的真实落笔语义可能有多种合理解释。

闭合曲线：1 个闭合 Stroke，无显式端点。

**仍不解决的内容：** 绘画的真实书写顺序、抬笔位置、笔触叠放层级、相交处谁上谁下，以及没有足够边界线索时的唯一语义分解。这些信息不能从现有论文算法及单张输入图像可靠确定。

### 10.3 验证

新增单元测试检查：X 的 2 条贯通路径与 J0 的两组配对；T 的贯通路径 + 终止路径；Y 不被误标成几何 T；闭合环无端点；三种新导出文件的结构、SVG 标签和 PNG 尺寸。当前测试集共 **15 项**，覆盖的是自制合成示例，不意味着复杂自然线稿完全正确。
